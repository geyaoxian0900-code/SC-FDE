# 第二章 SC-FDE 图形仿真

本目录用于复现论文第二章中具有数值仿真意义的图 2.3 至图 2.8：

- 图 2.3：数据块内双 UW 与单 UW 的 LS 信道估计 NMSE 对比。
- 图 2.4 至图 2.6：Chu、Frank-Zadoff、Zadoff-Chu 序列的时域星座、频域星座和频谱起伏。
- 图 2.7：三种 UW 序列的 LS 信道估计 NMSE 对比。
- 图 2.8：UW 长度对 SC-FDE 系统 BER 的影响。

图 2.1、图 2.2、图 2.9 至图 2.12 是系统结构图、流程图或 Tanner 图，不属于随机数值仿真，因此没有在脚本中重复绘制。

## 运行方法

在 MATLAB 中进入本目录并调用：

```matlab
run_chapter2_simulation
```

也可以在工程根目录使用命令行：

```powershell
matlab -batch "addpath('papers/chapter2_simulation'); run_chapter2_simulation"
```

结果保存在 `results` 目录，包括 PNG 图片、MATLAB 数据文件和 UW 频谱起伏 CSV。

图 2.3 同时输出静态信道和时变信道版本。时变版本文件为
`fig2_3_time_varying_block_structure_mse.png`。

## 与论文一致的参数

- FFT 块长度：512 点。
- 符号间隔：0.25 ms。
- 图 2.3 和图 2.7 的 UW 长度：64 点，即 16 ms。
- 图 2.7 的最大多径时延：5 ms 和 15 ms。
- 图 2.8 的 UW 长度：32、48、64、128 点。
- 图 2.8 的最大多径时延：15 ms 和 25 ms。
- 调制方式：QPSK。
- 信道估计：LS。
- 频域均衡：MMSE。

## 论文未给出的参数

论文没有给出四径信道的精确抽头位置、复增益、编码器参数、仿真帧数和随机种子。因此脚本采用以下可重复设置：

- 四径相对时延为最大时延的 `[0, 0.30, 0.68, 1.00]`。
- 四径复增益在 `four_path_channel` 函数中给出并归一化为单位能量。
- 图 2.3 的时变信道为四条路径分别叠加 `[0.25, -0.55, 1, -0.8]`
  倍最大多普勒的相位变化，默认最大多普勒为 12 Hz。
- 随机种子为 `20260722`。
- BER 仿真以 200 个错误或 100 万比特为停止条件。
- 未加入 LDPC 编码，以便单独观察 UW 保护长度造成的块间干扰。

因此，本仿真目标是验证论文中的物理趋势，而不是伪造与原图逐点相同的曲线。替换 `four_path_channel` 中的抽头即可使用实测水声信道。

## 需要特别注意的结果

按论文给出的标准定义和相同归一化，三种序列都是恒包络或近似 CAZAC 序列，其 FFT 幅度非常平坦。因此图 2.7 中三条 LS-NMSE 曲线理论上应基本重合。论文原图在高信噪比处给出了稳定的性能排序，但没有提供足以产生该差异的序列根参数、归一化方法或额外失配模型。

脚本保留这一可验证结果，不人为添加序列相关的误差地板。频谱图中约 `1e-13` 至 `1e-15` 的起伏主要来自浮点舍入误差，不能单独作为通信稳健性优劣的证据。

图 2.3 与图 2.8 的主要结论应当稳定出现：

- 相邻的第一个 UW 为第二个 UW 提供循环保护，因此双 UW 结构的信道估计误差更低。
- UW 长度大于最大多径时延后，SC-FDE 的循环卷积条件成立，BER 会显著下降。
- UW 短于信道时延时会产生块间干扰，即使继续提高 SNR，也会出现 BER 误差地板。
- 时变信道破坏了 UW 内的严格循环卷积关系，因此双 UW 曲线在高 SNR
  区域也会出现由模型失配决定的 NMSE 平层。
