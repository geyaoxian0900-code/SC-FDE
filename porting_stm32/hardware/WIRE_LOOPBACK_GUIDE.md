# 单板 DAC–ADC 有线回环指南（Wire Loopback Guide）

> 前置：烧录验收通过（见 FLASH_GUIDE.md）→ 单板纯数字回环 300/300 通过
> （`single_board_loopback.py`）。**在确认数字回环全过后再接线。**

## 1. 电平分析（先算后接）

| 项 | 值 | 依据 |
|---|---|---|
| DAC 输出范围 | 0 ~ VREF（3.3V 假设），中点 2048 → **1.65V**，幅度 ±700 码 → **1.086V ~ 2.214V** | `scfde_modem.c` SCFDE_TX_AMPLITUDE=700，`bsp_passband_tx.c` 2048±clip |
| ADC 输入范围 | 0 ~ VREF（3.3V），中点 2048 对应 **1.65V** | `bsp_passband_rx.c` ADC0 12bit 右对齐 |
| 直流中点 | 两侧一致（都是 2048 码 / 1.65V） | 设计匹配 |

**结论**：DAC 峰值 ±0.564V 在 ADC 输入范围内（无削顶），**可直接经衰减电阻连接**，
不需要隔直电容（两侧中点一致）；仍强烈建议加**分压电阻**（如 1kΩ 串 + 100Ω 并）
以便示波器观测与限流，并**保证共地**。

> ⚠️ 幅度 700 是编译时常量（`scfde_modem.c:27`）。若需更小幅度，
> 修改后重新编译（`twoboard_test.py` 的 D 组幅度扫描需要多版本固件）。

## 2. 接线（首次推荐：纯串联，无对地分压）

```
PA4 (DAC0) ──[1kΩ 串联]── PA0 (ADC0)
GND       ──────────────── GND
```

- **只允许串联限流电阻，严禁对地分压**：`1kΩ→PA0 + 100Ω→GND` 构成约 11:1
  对地分压，会把 DAC 的 1.65V 中点拉低到 ≈0.15V，破坏 ADC 所需的 2048 码
  中点（接收端减均值后出现巨大直流偏差，直接导致解调失败）。
- 两侧直流中点一致（都是 1.65V），串联电阻不改变中点，只限流。
- **共地**必须；电源一致（同一 3.3V）。
- 若确需衰减（例如后续接前置放大器时），两种正确做法：
  a) **以低阻抗 1.65V 为参考的分压**（如 DAC→R1→节点→R2→1.65V 参考源，节点接 PA0）；
  b) **隔直电容 + 重新偏置到 1.65V**（C 串接后，PA0 侧用大电阻接到 1.65V）。
  两者都需要示波器复核 PA0 静态电平 ≈1.65V。
- 若 PA0 已有前置放大/偏置电路，先断开，直接测 DAC→ADC。

## 3. 示波器检查（连接前/后）

| 检查项 | 预期 |
|---|---|
| 载波频率 | ≈ 12 kHz |
| DAC 波形中点 | ≈ 1.65V（2048 码） |
| 波形削顶 | 无（峰值 ≤ 2.214V） |
| **PA0 静态电平** | **≈ 1.65V**（若明显偏低=错误分压） |
| ADC 输入范围 | 0 ~ 3.3V 内，无负压 |
| 噪声底 | 明显低于信号 |

## 4. 流程：无单板模拟回环

> **当前固件无法做"同一块板 DAC→ADC 自动回环"**：
> `app_receive()`（`scfde_app.c:146-160`）会阻塞等待信号直到 5s 超时，
> 期间主循环无法执行"命令1发送"；半双工状态机不允许 TX/RX 同时启用；
> 且 `twoboard_test.py` 不能以同一 COM 口同时担任 TX 与 RX。
> 该模式需要新增专用固件测试命令（prepare TX → ADC DMA → DAC → 解码），
> 属于新固件特性，不在当前基线范围。

因此有线验证路径为：

```
单板纯数字回环（single_board_loopback.py，300 帧）
  → 两板 DAC–ADC 有线回环（twoboard_test.py，A/B/C/E 组）
```

## 5. 两板有线回环执行

按 `twoboard/README.md` 运行 `twoboard_test.py`（A=TX 板，B=RX 板），
或手动：A 板 role 2 发文本，B 板 role 3 收文本，循环 ≥ 20 帧。
每帧记录：

| 项 | 来源 |
|---|---|
| ADC 最大值/最小值/平均值 | 示波器统计或逻辑分析仪（固件不输出，记 NA） |
| 削顶样本数 | 示波器确认无削顶（记录 0/有） |
| 同步度量 / 帧起点 / CFO | 串口 `sync=` 行 |
| 信道抽头 | 当前固件不输出（`scfde_modem.c` 内部 28 抽头），记 NA |
| CRC | `RX OK` / `RX FAIL` |
| 连续通过率 | 累计统计 |

## 6. 验收

- 两板有线回环 **100% CRC 通过**（≥20 帧，最终以 1000 帧为准）
- CFO 记录值：同源时钟（同一电源/开发板电源轨）应接近 0；两板独立晶振时
  按 E 组统计，目标保持 **±10 Hz 内**（12 kHz 载波 ≈833ppm 总时钟裕量）
- 无削顶、无 HardFault

通过后进入两板独立时钟回环（`twoboard_test.py` 测试组 E）。
