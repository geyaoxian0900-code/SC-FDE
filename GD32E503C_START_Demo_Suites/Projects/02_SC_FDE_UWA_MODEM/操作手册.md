# GD32E503CE 水声单载波通信机操作手册

## 1. 适用范围

本手册适用于 `02_SC_FDE_UWA_MODEM` 工程。目标芯片为 GD32E503CE，
包含文字收发、QPSK、LDPC、UW 同步、多普勒补偿、信道估计，以及
频域和时域均衡器。

## 2. 当前物理层参数

| 参数 | 当前值 |
|---|---:|
| 帧结构 | `UW32 | UW32 | DATA96 | UW32` |
| 调制 | QPSK |
| 符号率 | 4 ksym/s |
| 载波 | 12 kHz |
| DAC 采样率 | 96 kHz |
| ADC 采样率 | 48 kHz |
| FFT 长度 | 128 |
| LDPC | `(192,128)`，码率 2/3 |
| 单帧文字载荷 | 最多 10 字节 |
| 串口 | 9600 baud，8-N-1 |

## 3. 接口与接线

| 功能 | 引脚 | 说明 |
|---|---|---|
| USART0 TX | PA9 | 连接 USB 转串口 RX |
| USART0 RX | PA10 | 连接 USB 转串口 TX |
| 模拟发射 | PA4 | DAC0，输出 12 kHz 通带波形 |
| 模拟接收 | PA0 | ADC0 通道 0 |
| 公共地 | GND | 单板、串口模块和模拟前端共地 |
| 发射使能 | PB0 | 仅在 `HALF_DUPLEX_CTRL_ENABLE=1` 时使用 |
| 接收使能 | PB1 | 仅在 `HALF_DUPLEX_CTRL_ENABLE=1` 时使用 |

当前 `bsp_half_duplex.h` 中半双工外部控制默认为关闭，因此 PB0、PB1
不会控制功放或接收前端。连接实际换能器前，应根据功放和前置放大器
的有效电平修改使能极性和保护时间。

> 不要直接把 PA4 接到 PA0。必须先确认 PA0 电压始终位于 ADC 允许
> 范围内，并通过衰减、限幅、滤波和约 1.65 V 直流偏置连接。数字
> 环回测试不需要任何 PA4/PA0 外部接线。

## 5. 上电和串口

打开串口终端并设置为 `9600, 8-N-1, 无流控`。复位后先选择节点角色：

```text
Select node role:
  1: local diagnostic (no external wiring)
  2: transmitter node
  3: receiver node
  4: manual transceiver
role>
```

本机调试只显示环回命令；仅发射节点只显示发送命令；仅接收节点只显示
接收命令；手动收发节点同时显示发送和接收。所有角色都可以切换均衡
器和执行全部均衡器自检。输入 `0` 可随时返回角色选择。

角色内命令编号固定：

```text
1: 发送文字（仅发射/手动收发）
2: 接收一帧（仅接收/手动收发）
3: 当前均衡器数字环回（仅本机调试）
4: 切换均衡器
5: 测试全部均衡器
0: 返回角色选择
```

## 6. 菜单操作

### 6.1 发送文字

上电选择角色 `2` 或 `4`，再输入 `1`。在 `Text:` 后输入最多 10 个
单字节字符并回车。当前固件按
字节分帧，UTF-8 中文通常超过 10 字节，建议硬件初测先使用 ASCII。

正常输出示例：

```text
TX OK: seq=0 len=6 samples=4608 duration=48 ms
```

### 6.2 接收一帧

上电选择角色 `3` 或 `4`，再输入 `2`。接收机等待信号，默认超时约
5 秒。发送端应在接收端
显示 `Waiting for acoustic signal...` 后再发送。

成功输出包括：

```text
sync=... start=... CFO=... Hz EQ=MMSE-FDE
RX OK: seq=... len=... data(hex)=... data(text)=...
```

其中 `sync` 是 UW 同步度量，当前最低阈值为 0.18；`CFO` 是估计的
残余频偏；`EQ` 是实际完成 CRC 解码的均衡器。

### 6.3 当前均衡器数字环回

上电选择角色 `1`，再输入 `3`。固件直接把内部 DAC 波形转换为 ADC
样本，再运行完整接收
链路，不需要外部接线。该测试用于确认帧、同步、均衡、LDPC 和 CRC。

### 6.4 切换均衡器

每输入一次 `4`，均衡器按以下顺序循环：

```text
AUTO -> MMSE-FDE -> ZF-FDE -> MF-FDE -> IB-DFE -> NLMS-TDE -> AUTO
```

- `MMSE-FDE`：默认推荐，兼顾噪声放大和多径抑制。
- `ZF-FDE`：深衰落下可能明显放大噪声。
- `MF-FDE`：稳定但不能完全消除码间干扰。
- `IB-DFE`：两次频域判决反馈，适合较强多径。
- `NLMS-TDE`：真正的时域均衡；用 UW 训练 16 抽头 FIR，不使用 FFT。
- `AUTO`：按 MMSE、IB-DFE、NLMS-TDE、ZF、MF 顺序尝试，以 CRC 选择。

### 6.5 测试全部均衡器

输入 `5`。同一个内部数字环回帧会依次通过所有固定均衡器，输出：

```text
MMSE-FDE: PASS
ZF-FDE  : PASS
MF-FDE  : PASS
IB-DFE  : PASS
NLMS-TDE: PASS
```

测试结束后会恢复之前选中的均衡模式。烧录后的第一项操作应当是菜单
`5`；如果某种算法失败，再单独选中该算法并使用菜单 `3` 检查详情。

## 7. 推荐测试流程

1. 不接模拟前端，执行菜单 `5`，确认全部数字环回通过。
2. 通过带偏置和衰减的线缆连接发射与接收前端，先使用 `MMSE-FDE`。
3. 调整输入幅度，使 ADC 不削顶且能超过信号检测阈值。
4. 使用两块板进行单向发送和接收测试。
5. 固定距离和增益，依次比较各均衡模式的成功率。
6. 强多径环境优先比较 `MMSE-FDE`、`IB-DFE` 和 `NLMS-TDE`。
7. 完成稳定线缆测试后，再连接功放、换能器和水池/湖试链路。

## 8. 常见故障

### 串口没有输出

检查 PA9/PA10 是否交叉连接、是否共地，以及终端是否为 9600 8-N-1。

### 菜单 2 一直超时

检查 PA0 是否存在带 1.65 V 偏置的接收信号。默认信号检测采用短时
峰峰值门限，输入幅度太小不会启动整帧 DMA 采集。

### 有同步但 CRC 失败

先运行菜单 `5` 排除数字链路问题，再检查 ADC 削顶、载频偏差、采样
时钟、多径时延是否超过 UW 保护长度。可先选择 `AUTO`，观察最后输出
的 `EQ`；若所有方法均失败，应优先改善模拟信噪比和同步条件。

### ZF 失败而 MMSE 成功

这是深衰落下的正常现象。ZF 会对接近零的信道频点做较大增益，MMSE
通过正则化限制噪声放大。

### NLMS-TDE 失败而 FDE 成功

16 抽头 TDE 的覆盖长度和训练长度均有限。长时延扩展水声信道更适合
128 点 FDE；也可增大 TDE 抽头数，但会增加每符号乘加次数和训练时间。

## 9. MATLAB 配套验证

在工程的 `matlab` 目录运行：

```matlab
verification = verify_scfde_project();
summary = run_all_scfde_simulations(struct("profile","quick"));
launch_scfde_text_app
```

交互程序可显示文字分包、调制、发射波形、信道、接收波形、同步度量、
均衡星座、CRC 和恢复文字。MATLAB 中的参数可修改；硬件固件仍采用本
手册第 2 节列出的编译时物理层参数。

## 10. 修改参数的位置

- 物理层和帧参数：`scfde_modem.h`
- 均衡算法参数：`scfde_equalizer.c`
- 信号检测门限：`bsp_passband_rx.c`
- 半双工使能和保护时间：`bsp_half_duplex.h`
- 串口菜单：`main.c`

修改 FFT、UW、DATA 或 LDPC 长度时，必须同时检查数组大小、帧持续时间、
接收 DMA 长度和 MATLAB 参数，不能只修改单个宏。
